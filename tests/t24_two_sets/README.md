t24: one header in two header-unit sets of the same directory, each set imported by its own target (t24_a: hu_one, t24_b: hu_two): <vector>, and <t24/val.h>, which hu_two spells <val.h> (the same file). GCC: the second set is rejected at configure time (one header unit per header per build tree). Clang, clang-cl, MSVC: each set builds its own header unit at its own path, each consumer reads only its own set's, and a deleted BMI is rebuilt alone with its consumer.
