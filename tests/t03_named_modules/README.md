t03: coexistence with CMake's native named modules (FILE_SET CXX_MODULES). Module m does `export import <vector>;` (a header unit inside the module purview). The executable t03 does `import m; import <string>; import <iostream>;`. t03_other is ANOTHER target that imports m (cross-target BMI use) and needs no header-unit flags itself; the driver checks that no synthetic BMI target is created for it. A second tree with -DT03_SYNTH=ON adds an importer with target-level -O2, the Kitware #28166 case: CMake synthesizes m@synth_N, and the driver checks that its object order reaches the set's _ready target and that the tree builds, runs and is a no-op afterwards. Boundary probe p_m2_consumer: module m2 with a NON-exported `import <vector>;` whose importer uses std::vector members.
