t26: one source in two targets that ask for different things. src/plain.cpp (`#include <t26.h>`) is compiled by t26_imp (directory a), which imports the set, and by t26_plain (directory c), which does not: a clean `ninja t26_plain` builds without the header unit, the #include stays textual (with GCC the compile's mapper finds the source's map only for the targets that import header units for it), and after an edit of the header `ninja t26_plain` rebuilds it without building the header unit.
